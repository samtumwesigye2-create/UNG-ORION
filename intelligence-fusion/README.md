# UNG ORION — Intelligence Fusion (prototype)

Mobile-friendly, self-contained static demonstration for ORION. Open `index.html` locally or through a static preview. No installation or backend required.

Features: synthetic relationship graph, chronological events, schematic geospatial observations, source table and search. No real surveillance data or external dependencies.

**Not production-ready:** No authentication, access controls, server-side import, persistence, audit trail, provenance verification, or real map tiles. Do not load sensitive data into this demonstration. Review security and integrate into the existing ORION app before deployment.

This code is intentionally committed to the feature branch, **not main**, so Railway's main-branch auto-deploy is not triggered. Merge only when ready to deploy.
